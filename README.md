# HTML, CSS & Bootstrap Practice Programs

## 📌 About This Repository

This repository contains my practice programs and hands-on exercises developed while learning and improving my frontend web development skills using HTML, CSS, and Bootstrap.

It includes basic to intermediate concepts, coding exercises, webpage designs, layouts, and responsive web development practices.

The main goal of this repository is to strengthen my frontend development fundamentals through practical implementation.

## 🎯 Objectives

- Learn and practise HTML fundamentals.
- Understand CSS styling and layouts.
- Develop responsive web pages using Bootstrap 5.
- Improve frontend development skills through hands-on coding.
- Build interactive and user-friendly web interfaces.
- Maintain a collection of practice programs for future reference.

## 🛠️ Technologies Used

- **HTML5** – Webpage structure and content.
- **CSS3** – Styling, layouts, animations, and responsiveness.
- **Bootstrap 5** – Responsive layouts and prebuilt UI components.
- **JavaScript** – Basic client-side interactivity (where applicable).

## 🚀 How to Run the Programs

1. Clone this repository:

   ```bash
   git clone <your-github-repository-url>
   ```

2. Open the project folder in Visual Studio Code.

3. Navigate to the required HTML file.

4. Open the HTML file in your browser or use the VS Code Live Server extension.

5. Explore and practise the examples.
